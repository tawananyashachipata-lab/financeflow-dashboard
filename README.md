# FinanceFlow Dashboard

A modern, professional personal finance management web app built with React, TypeScript, and TanStack Start.

## Purpose

FinanceFlow helps young adults easily understand where their money goes, manage budgets, track expenses, and work toward savings goals.

## Features

- **Dashboard** — Total balance, monthly income/expenses, savings, budget progress, recent transactions, and spending-by-category overview.
- **Transactions** — Searchable and filterable list of income and expenses with category and type filters.
- **Budget** — Monthly category budgets with progress bars showing spent vs. remaining amounts.
- **Savings Goals** — Track goals with target amount, saved amount, percentage progress, and remaining amount.
- **Analytics** — Charts for income vs expenses, spending by category, monthly trends, and savings growth.
- **Settings** — Profile information, currency preference, notification preferences, and appearance settings.

## Design

Clean, modern fintech design with a deep navy primary color, emerald green accents, rounded cards, subtle shadows, and the Inter font.

## Development

### Prerequisites

- Node.js 20+
- npm, yarn, or bun

### Setup

```sh
git clone <repository-url>
cd financeflow-dashboard
npm install
npm run dev
```

### Scripts

| Command           | Description                  |
| ----------------- | ---------------------------- |
| `npm run dev`     | Start the development server |
| `npm run build`   | Build for production         |
| `npm run preview` | Preview the production build |
| `npm run lint`    | Run ESLint                   |
| `npm run format`  | Format code with Prettier    |
